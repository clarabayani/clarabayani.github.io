# Clara Bayani Portfolio

GitHub Pages-ready personal portfolio for Bienvenida Clara Vega Bayani.

## Publish on GitHub

1. Open the `clarabayani.github.io` repository.
2. Click **uploading an existing file**.
3. Drag these items into the upload area:
   - `index.html`
   - `styles.css`
   - `script.js`
   - the entire `assets` folder
4. Click **Commit changes**.
5. Wait 1–5 minutes, then visit `https://clarabayani.github.io`.

Do not upload the ZIP itself. Extract it first, then upload the files inside.
